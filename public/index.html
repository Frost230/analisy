Endpoints disponíveis

POST /api/inicializar - enviar JSON com player para registrar a inicialização do script. POST /api/analisar - enviar JSON com player e texto para registrar o comando. GET /api/comandos - obter os comandos pendentes e marcar como atendidos. GET /api/comandos/historico - consultar todo o histórico de pedidos, atendimentos e inicializações.
